\# Описание ключевых Use Case



\## Use Case 1. Формирование отчёта



| Поле | Значение |

|---|---|

| \*\*Название\*\* | Формирование отчёта |

| \*\*Актор\*\* | Аналитик (также Коммерческий директор, Менеджер по продажам) |

| \*\*Предусловие\*\* | Пользователь авторизован, данные о продажах загружены в систему |

| \*\*Основной поток\*\* | 1. Пользователь выбирает тип отчёта.<br>2. Указывает период.<br>3. Нажимает «Сформировать».<br>4. Система формирует отчёт.<br>5. Пользователь просматривает отчёт. |

| \*\*Альтернативный поток\*\* | Если данных за выбранный период нет — система выводит сообщение «Данные за период отсутствуют». |

| \*\*Постусловие\*\* | Отчёт сформирован и доступен для экспорта в Excel. |

\## Use Case 2. Просмотр дашборда KPI



| Поле | Значение |

|---|---|

| \*\*Название\*\* | Просмотр дашборда KPI |

| \*\*Актор\*\* | Коммерческий директор (также Аналитик) |

| \*\*Предусловие\*\* | Пользователь авторизован, данные о продажах загружены в систему |

| \*\*Основной поток\*\* | 1. Пользователь открывает главную страницу.<br>2. Система отображает дашборд с KPI: выручка, средний чек, конверсия, рентабельность.<br>3. Пользователь выбирает период (например, «Последний месяц»).<br>4. Система пересчитывает и обновляет KPI.<br>5. Пользователь анализирует показатели. |

| \*\*Альтернативный поток\*\* | Если данные не загружены — система выводит сообщение «Нет данных для отображения. Загрузите данные о продажах». |

| \*\*Постусловие\*\* | Пользователь получил актуальную информацию о KPI. |

\## Use Case 3 (дополнительно). Загрузка данных о продажах



| Поле | Значение |

|---|---|

| \*\*Название\*\* | Загрузка данных о продажах |

| \*\*Актор\*\* | Менеджер по продажам |

| \*\*Предусловие\*\* | Пользователь авторизован и имеет роль «Менеджер по продажам» |

| \*\*Основной поток\*\* | 1. Пользователь открывает раздел «Загрузка данных».<br>2. Выбирает файл (CSV/Excel).<br>3. Нажимает «Загрузить».<br>4. Система проверяет формат файла.<br>5. Система сохраняет данные и подтверждает успешную загрузку. |

| \*\*Альтернативный поток\*\* | Если формат файла неверный — система выводит сообщение об ошибке и предлагает скачать шаблон. |

| \*\*Постусловие\*\* | Данные о продажах загружены и доступны для расчёта KPI. |
